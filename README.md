# Grad Ready: app prototype

Clickable prototype for the MCRA Week 13 presentation (SMU SCIS, Managing Customer Relations with Analytics). Grad Ready helps Year 4 students see every graduation requirement on one page, get an early warning before the final term, and get fast replies from advisors.

Everything on screen is **sample data** and says so.

## Run it

Download `06-app/index.html` and double-click it. It runs in any browser, with no install.

## Where things are

| File | What it is |
|---|---|
| `06-app/index.html` | The whole prototype (single file) |
| `06-app/DESIGN.md` | Colours, type, components and tone, so the app, posters and slides match |
| `06-app/README.md` | What each view does, and what is left to do |

## Working rules

- Pull before you start, push when you finish. Example commit message: `app: add interview-leave policy text`.
- Keep all data labelled as sample or illustrative. Don't invent real statistics.
- No personal data (names, emails, student IDs) in the repo.
