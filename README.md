## Working rules

- **Stay in your own folder.** This avoids merge conflicts, since most of our files (PDF, .twbx, .pptx) can't be merged.
- **Pull before you start, push when you finish a session.** Commit message example: `vpc: first draft of jobs and pains`.
- **Name files with a version:** `Tableau_Story_v3.twbx`, not `final_FINAL.twbx`. Only Person 8 marks something as final.
- **No personal data in the repo.** Survey responses must be anonymised (no names, emails or student IDs) before they are committed.
- **Don't invent data.** Anything simulated must be labelled as illustrative.
- Large Tableau files: keep under 50 MB. If a file is bigger, share it through the class drive and link it here.
